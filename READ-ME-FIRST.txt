HUNARSAAZ PORTAL — LIVE LECTURES
================================

Goes to   /home2/lqonfyud/hunarsaaz-portal   (NOT public_html)


YOUR DATABASE IS NOT TOUCHED
----------------------------

There is deliberately NO data folder and NO .env file in this zip, so
neither can be overwritten.

You keep your admin account, your instructors and photographs, your
students, enrolments and payment records, and your settings.

This release ADDS two tables to your database when it starts, for the
classes and the attendance register. It creates them only if they are
missing and changes nothing that is already there. Your 45 courses and
everyone's progress are untouched.


WHAT IS NEW
-----------

Live online classes.

    An instructor schedules a class and attaches it to a course
    Only students enrolled on that course can join
    The instructor presses Start, students join from inside the portal
    Students arrive muted with cameras off, as you want in a lecture
    The register records who joined and for how long
    A recording link can be added to the class afterwards

Students see "Live Classes" in the portal menu, and their next class on
their dashboard. Instructors see "My Classes".


BEFORE ANY OF IT WORKS: THE VIDEO SERVER
----------------------------------------

The video does not run on this hosting and cannot. A video server needs
open UDP ports, a public address and real bandwidth; cPanel shared
hosting has none of them.

Read video-server-setup.md in this zip. It walks through renting a small
server (about €15-25 a month), pointing meet.hunarsaaz.pk at it, and
installing Jitsi, including the two settings that let one machine carry
a class of a hundred.

Until that server exists you can still schedule classes — you simply
cannot hold one. The portal says so plainly rather than failing.


STEP 1 — BACK UP THE DATABASE
-----------------------------
cPanel > File Manager > /home2/lqonfyud/hunarsaaz-portal > data

Right-click hunarsaaz.db > Download. One file. This release writes to
your database for the first time, so take the backup — it is how you get
back if anything goes wrong.


STEP 2 — STOP THE APP
---------------------
cPanel > Setup Node.js App > your application > Stop


STEP 3 — DELETE ONLY THESE FIVE
-------------------------------
In /home2/lqonfyud/hunarsaaz-portal, delete:

    .next
    node_modules
    src
    server.js
    package.json

DO NOT DELETE:

    data              your database
    .env              your settings and password key
    public            your uploaded photographs are in public/uploads
    private-uploads   student work

Turn on File Manager > Settings > Show Hidden Files to see .next and .env.


STEP 4 — UPLOAD AND EXTRACT
---------------------------
This release comes as three zips because the whole thing is too big to
download in one piece:

    portal-part1-app.zip
    portal-part2-next.zip
    portal-part3-rest.zip

Upload all three into hunarsaaz-portal, then extract each one in turn.
Order does not matter, but all three must be extracted or the app will
not start. Delete the zips afterwards.


STEP 5 — ADD THE VIDEO SETTINGS
-------------------------------
Only once the video server from video-server-setup.md is running.

Right-click .env > Edit, and add three lines at the end:

    JITSI_DOMAIN=meet.hunarsaaz.pk
    JITSI_APP_ID=hunarsaaz
    JITSI_APP_SECRET=the-secret-you-set-on-the-video-server

The id and secret must match the video server exactly. If they do not,
students reach the class and are thrown straight back out.

Leave everything else in the file alone, especially PAYLOAD_SECRET —
changing that logs everybody out.


STEP 6 — START IT
-----------------
Setup Node.js App > Start

DO NOT click "Run NPM Install".


STEP 7 — CHECK
--------------
Open https://learn.hunarsaaz.pk/learn/live and press Ctrl+Shift+R.

You should get the Live Classes page saying no classes are scheduled.
If instead you get an error, the two new tables were not created: tell
me, and send what the page says.

Then sign in as an instructor, press "My Classes", and schedule one.


A NOTE ON RECORDING
-------------------

Jitsi can record, but it needs a second server to do it, because it runs
a whole browser to make the recording. For now the simpler path is for
the instructor to record their own screen, upload it wherever you like,
and paste the link into the finished class — the portal has a box for
that and shows it to enrolled students.
